# sistema-pizzeria
Tpi prog 3

Se realizo un sistema web, donde tendremos los roles Admin y usuario. El sistema se basa en una pizzeria, donde el usuario puede registrarse e iniciar sesión para ver el menú, agregar productos (pizza y bebida) al carrito, realizar el pedido y ver sus pedidos, junto al estado. 
Desde la vista de admin, tendremos un dashboard donde comprobaremos el dinero de ventas totales, pedidos, grafico donde se ven los estados de los pedidos (pendiente, en preparación y entregado)
Luego podremos gestionar el menu, con un CRUD funcional sobre los productos ofrecidos. Tambien gestionar pedidos entrantes.
